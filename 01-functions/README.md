# 01 — Functions

**Level:** Level 1 | **Status:** 🚧 Planned (not yet written)

Functions are the base unit of every AI pipeline step, tool call, and API handler. This module goes past the basics into how Python actually passes and binds arguments.

## What this module will cover

- `*args` and `**kwargs`
- Default arguments and the mutable-default trap
- First-class functions and closures
- Higher-order functions
- Functional patterns used in pipelines (`map`, `filter`, `functools`)
