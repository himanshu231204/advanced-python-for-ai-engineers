# 02 — Iterators & Generators

**Level:** Level 1 | **Status:** 🚧 Planned (not yet written)

Generators are how Python streams data without loading everything into memory — the same idea behind token streaming and lazy data pipelines in AI systems.

## What this module will cover

- Iterator protocol (`__iter__` / `__next__`)
- Generator functions and `yield`
- Generator expressions
- `yield from`
- Lazy evaluation and memory tradeoffs
