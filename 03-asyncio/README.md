# 03 — Asyncio Fundamentals

**Level:** Level 1 | **Status:** 🚧 Planned (not yet written)

`async`/`await` is the backbone of every modern AI backend: LLM calls, vector DB lookups, and tool calls are all I/O-bound and benefit from concurrency, not parallelism.

## What this module will cover

- Coroutines and the event loop
- `async def` / `await`
- Awaitables vs coroutines
- Why asyncio helps I/O-bound work (and not CPU-bound work)
- Common blocking-call mistakes
