# 10 — Advanced OOP & Magic Methods

**Level:** Level 4 | **Status:** 🚧 Planned (not yet written)

- `__iter__` / `__next__`
- `__aiter__` / `__anext__`
- `__enter__` / `__exit__`
- Descriptors
- Operator overloading (used sparingly)
