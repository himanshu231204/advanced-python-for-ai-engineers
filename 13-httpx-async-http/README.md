# 13 — HTTPX & Async HTTP

**Level:** Level 3 | **Status:** 🚧 Planned (not yet written)

Nearly every AI system call — LLM API, vector DB, search API — goes over HTTP. HTTPX's async client is the standard tool for calling them concurrently.

## What this module will cover

- Sync vs async HTTPX clients
- Connection pooling and client reuse
- Timeouts and retries at the HTTP layer
- Calling multiple APIs concurrently
