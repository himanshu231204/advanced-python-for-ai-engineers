# 15 — Error Handling & Retries

**Level:** Level 3 | **Status:** 🚧 Planned (not yet written)

LLM APIs fail, rate-limit, and time out. Knowing what's retryable — and how to back off correctly — is the difference between a resilient system and a cascading outage.

## What this module will cover

- Exception hierarchies and custom exceptions
- Retry vs fail-fast decisions
- Exponential backoff with jitter
- Circuit breakers
- Rate limiting
