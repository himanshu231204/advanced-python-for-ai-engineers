Each project combines multiple modules from the numbered curriculum into a small, realistic
AI-engineering build. These are where the individual concepts (asyncio, Pydantic, decorators,
streaming, etc.) come together into something closer to production code.

| # | Project | Primary modules used |
|---|---------|-----------------------|

| 02 | [Streaming LLM API](02-streaming-llm-api/) | async generators, FastAPI, SSE, Pydantic |
| 03 | [Concurrent RAG Pipeline](03-concurrent-rag-pipeline/) | concurrency, HTTPX, fan-out/fan-in |
| 04 | [Agent Tool Executor](04-agent-tool-executor/) | protocols, async tool calls, retries |
| 05 | [Production AI Service](05-production-ai-service/) | FastAPI, config, caching, testing, logging |
| 06 | [LangGraph-Oriented Python Patterns](06-langgraph-oriented-patterns/) | typed state, async nodes, streaming |

Each project folder will contain its own `README.md` with requirements, architecture, and a
runnable implementation once written.
